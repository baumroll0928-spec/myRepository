# OSINT

## 問題
AlpacaHack上にて、あるユーザーによる不審な活動が確認された。

初期調査の結果、当該ユーザーは複数のオンラインサービスにおいて、同一のユーザーネームを使い回している可能性があることが判明している。

調査担当者であるあなたには、このユーザーのオンライン上の痕跡を追跡し、公開情報や過去の発信内容などをもとに、その人物の 「好きなUnicode文字」 を特定してもらいたい。

最終的に、特定したUnicode文字を Alpaca{Unicode文字} の形式でフラグとして提出せよ。
例えば、「🦙」が好きだと判明したら Alpaca{🦙} が答えとなる。

調査対象のユーザーネームは baumroll1234 だ。

## 概要

Daily AlpacaHackでOSINTなんて珍しいなあと思ったら・・・

え？私？

私が好きなUnicode文字って何なのでしょうか？

自分でもわからないのに他の人はわかるのでしょうか？

いやその前に何で私なんでしょうか？

最近ときどきWriteupを投稿していてアンケートもちゃんと回答しているので運営さんたちの目に留まったのでしょうか？（だとしたらちょっと嬉しいけど。）

そして「不審な」とはどういうことでしょうか？私なにか悪いことでもしちゃったんでしょうか？

謎は深まるばかりです。

## 解法

OSINTということなので、とりあえず
```
baumroll1234
```
でGoogle検索してみると、まあ当然というかなんというか、Daily AlpacaHackのページばかりヒットします。そこで、
```
baumroll1234 -site:alpacahack.com
```
でAlpacaHackのサイトを除外して検索すると、今度は１件もヒットしなくなります。

確かにX(旧Twitter)も同じアカウント名ですが、こっちは何もポストしていないいわゆる見る専のアカウントなので関係なさそうです。

完全に詰んだのでヒントを見てみます。
```
今日はエイプリルフールです。
```
あーそうかエイプリルフールだったかー！

・・・わかりません。

まあとりあえず、ものは試しということで、AlpacaHackに挑んでいる人たちはみんなアルパカ🦙大好きなんじゃないの？という雑な理屈で
```
Alpaca{🦙}
```
を提出してみたら、通ってしまいました（笑）

その後、同じくAlpacaHackユーザーの知人に私が問題の題材になってるよって自慢したところ、その人も自分のユーザー名が表示されていることが判明しました。

試しにログアウトしてから問題を表示したらどうなるか試したところ、
```
この問題を見るには サインイン してください。
```
と表示されることからも間違いなさそうです。

しかも、その人は
```
Alpaca{💩}
```
で通ったみたいです。💩って・・・（笑）

## 結論

* みんな自分のAlpacaHackのユーザー名が表示されているっぽい。
* Unicode文字なら何でも良かったっぽい。
