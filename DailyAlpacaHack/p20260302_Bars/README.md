# Bars

## 問題

Bars, bars, and more bars.

## 解法

指定のURLをブラウザで開いてみると、
```
FLAG: Alpaca{|1||I|l1|IIIl1|1lII|1II|1|I|||...
```
数字のイチ、大文字のアイ、小文字のエル、パイプ記号が並んだフラグが表示されています。

何かの暗号でしょうか？とりあえず文字列をコピーしてみましょう。

・・・あれ、文字選択ができない？

それなら、右クリック→ページのソースを表示でしょうか。

・・・右クリックも効かない？

添付のapp.pyを見てみると、Javascriptで主要なイベントがことごとく握り潰されているようです。

解決方法をいくつか考えてみます。

### 方針１：がんばる

解像度がそこそこ高いディスプレイでウィンドウを最大化すれば全部表示できるので、手打ちで写すことができます。

しかし、シンプルに面倒くさすぎる、見間違いや打ち間違いのリスクがあるといった理由からあまり現実的ではないかもしれません。

### 方針２：JavascriptをOFFにする

chromeブラウザの場合（以下同じ）、三点メニュー→設定→プライバシーとセキュリティ→サイトの設定→Javascriptで、Javascriptの使用を許可しないサイトにURLを追加すると、そのサイトではJavascriptが無効になり、右クリック→ページのソースを表示ができるようになります。

※文字の選択についてはJavascriptではなくCSSで制限されているのでこの方法ではできないようです。

#### 注意（2026/03/08追記）

後で気づいたのですが、この設定が有効のままだと３日後の「Alart my flag」の解答に支障が出ます。終わったら速やかに無効化を削除した方が良いです。

### 方針３：ページを保存する

三点メニュー→キャスト、保存、共有→名前を付けてページを保存で、html形式でページを保存できるので、テキストエディタで開いて確認できます。

### 方針４：デベロッパーツールを使う

キー押下イベントが潰されているのでF12やCtrl+Shift+Iで開くことはできませんが、ブラウザのメニューからは開くことができます。

三点メニュー→その他のツール→デベロッパーツール

開いたら、Sourcesタブでtop > 34.170.146.252:55224 > (index)からソースを表示することができます。

### 方針５：Pythonのrequestsモジュールを使う

```py
import requests
import re

URI = "http://34.170.146.252:55224/"

r = requests.get(URI, timeout=10)
match = re.search(r'Alpaca\{.+?\}', r.text)
if match:
    flag = match.group(0)
    print(flag)
```

### 方針６：curlコマンドを使う

```sh
curl http://34.170.146.252:55224/ | grep "Alpaca{"
```
