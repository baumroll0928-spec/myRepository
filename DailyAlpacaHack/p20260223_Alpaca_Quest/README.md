# Alpaca Quest

## 問題

アルパカの村に迷い込んだ、新米冒険者。

## 方針

データを覗いてカンニングする。

## 解法

alpaca-quest.apkというファイルが配布されています。

調べてみると、Androidのアプリをインストールするためのファイルのようです。

私のケータイはiPhoneのため手元にAndroid端末が無いので、パソコンにAndroid Studioをインストールして実行してみました。

アプリを起動して、Alpaca Questの文字、アルパカのイラストとともに表示されるスタートボタンを押してみます。

すると、
```
アルパカが立ちはだかっている!
「フラグは渡さないパカ!」
```
なにやらご立腹のようです。

その下の「説得する」ボタンを押してみます。すると、
```
アルパカの心の壁を1削った!
```
というメッセージとともにHP(?)のゲージが少し減少します。

何回か押していると、フラグの末尾と思われる
```
}
```
が顔を出します。

このまま何回も連打すればいいのかな？と思ったら、突然
```
アルパカが激しく動揺した!
あなたは強烈なキックを浴びた!
意識が遠のく…
```
どうやらアルパカに思いっきり蹴られてゲームオーバーになってしまったようです。

ところでアルパカって本当に蹴ってくるんでしょうか？あの巨体で思いっきり蹴られたらひとたまりもなさそうです。

さて、フラグを得るにはアルパカが動揺する前にゲージを削り切る必要がありそうですが、そのためには高橋名人もビックリの高速連打が必要そうです。

凡人の私にはとうてい無理なので、別の方法を考えます。

apkファイルをstringsコマンドで調べてみます。
```sh
$ strings alpaca-quest.apk | grep "Alpaca{"
$
```
さすがに世の中そんなに甘くはありませんでした。

バイナリを覗いてみます。
```sh
$ xxd -l 64 alpaca-quest.apk
```

最後の方にPK\x05\x06があり、その少し前にPK\x01\x02もあります。

これはZIPファイルですね。

apkファイルもワードやエクセルのファイルと同様にその正体はZIPファイルのようです。

あとapkってアルパカに似てるなぁと思ったけどアルパカのカはkaじゃなくてcaでした。

ZIPファイルなので展開してみます。
```sh
unzip alpaca-quest.apk -d files
```

展開できたら、フラグを探してみます。
```
$ grep -R "Alpaca{" files
grep: files/classes3.dex: binary file matches
grep: files/res/layout-land/activity_main.xml: binary file matches
```

２つあるようですが、バイナリファイルのためこのままでは表示できないようです。

再度stringsコマンドで調べてみます。
```sh
$ strings files/classes3.dex | grep "Alpaca{"
#Alpaca{***************************}
$ strings files/res/layout-land/activity_main.xml | grep "Alpaca{"
##Alpaca{***************************}
```

あれ、フラグが出た？

意外とあっさりフラグが取れました。
