# Heuristic IPPON

## 問題

目指せIPPON！

まずはコードを見ずにチャレンジしてみてください！

## 概要

「まずはコードを見ず」にとのことなので、見ないで実行してみます。
```sh
$ nc 34.170.146.252 59419
お題：こんなCTFは嫌だ。どんなCTF？
回答：
```
どうやら大喜利のようです。いろいろ入力してみました。

```sh
回答：Miscジャンルしかない
■■■■■■■□□□ 7点
回答：フラグの長さがすべて1024文字
■■■■■■■■■□ 9点
回答：Chaos Trouble Failureの略だった
□□□□□□□□□□ 0点
回答：フラグでめっちゃ罵倒してくる
■■■■■■□□□□ 6点
回答：「今何問目？」という問題がある
■■■■■■□□□□ 6点
回答：間違ったフラグを提出すると上からたらいが落ちてくる
□□□□□□□□□□ 0点
回答：ユーザーが自分しかいない
■■■■□□□□□□ 4点
回答：未解決問題の証明を求めてくる
■■■■■■■■■□ 9点
回答：フラグじゃなくて揚げ足を取らせる
■■■■■■□□□□ 6点
```
入力に対して、10点満点で採点されるようです。満点をとったらフラグが表示されるといったところでしょうか。

## 方針

あきらめてソースコードを見る。

## 解法

同じ入力に対しては同じ点数になるので、ランダム要素は無く何らかの定められた採点基準があるようです。

ただ、その採点基準は全くわからないので、あきらめてソースコードを見てみます。

すると、CTF_WORDS、IYADA_WORDS、SENTENCE_WORDSをすべて含みかつ12文字以上13文字以下の時に満点が取れることがわかりました。

よって、例えば
```sh
回答：マイナンバーがフラグだった
```
が正解となります。
