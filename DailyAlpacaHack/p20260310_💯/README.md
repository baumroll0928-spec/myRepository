## 概要

100問目ということで、100にちなんだ問題のようです。

ちょっと読みにくいので変数名を変えてみます。
```py
myset = set()
for i in range(100):
    txt = input("100? ").strip()
    assert txt.isascii()
    assert len(txt) <= 10.0
    assert txt not in myset
    assert int(txt) == 100
    myset.add(txt)
```
左右の空白除去、非アスキー文字無し、長さ10以下で、int()によって100と評価される異なる100個の文字列の入力が求められているようです。

## 方針

頭の"0"追加と数字間の"_"挿入で種類を稼ぐ。

## 解法

私が最初に思い付いたのはこれでした。
```
100.00
100.01
100.02
...
100.98
100.99
```
float小数の100.01などはint()で100と評価されます。

しかし、 str文字列の"100.01"をint()にかけるとValueErrorになってしまうようです。

次に思い付いたのはこんなのです。
```
00100
+100
```
先頭の空白は全て除かれてしまいますが、"+"や"0"を付けることは許されます。

しかし、10文字以下の文字数制限から、この方法だけだと14種類しか稼ぐことができず、100種類には到底及びません。

ここで、Pythonでは1_000_000_000_000のように整数を_で区切って表記できることを思い出しました。

これは文字列でも同じように書けるのでしょうか？試してみます。
```py
x = int("01_00")
print(x == 100)
```
```
True
```
書けるようです。

ということで、"100"～"0000000100"の間に長さが10を越えない範囲で"_"をあらゆる位置に入れてみます。

これで100個以上稼げるでしょうか？足りなければ"+"の使用も検討しなければいけません。
```py
def generate100():
    for i in range(7):
        a = "0" * i + "100"
        for m in range(1 << (i + 2)):
            s = ""
            for j in range(len(a)):
                s += a[j]
                if m & (1 << j):
                    s += '_'
            if len(s) <= 10:
                yield s
cnt = 0
for s in generate100():
    print(s)
    cnt += 1
print(f"{cnt = }")
```
```
100
1_00
10_0
1_0_0
0100
0_100
...
0000001_00
00000010_0
cnt = 139
```
139個！十分あるようです。
