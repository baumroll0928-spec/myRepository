# Alpaca Nation

## 問題

🦙 < アルパカ個体数が世界で最も多いとされる国はどーこだ？

国名を英語でフラグ形式で答えてください。例えば、答えが「Japan」であればフラグは Alpaca{Japan} です。

## 解法

Googleで「アルパカの数が世界一多い国」を[検索](https://www.google.com/search?q=%E3%82%A2%E3%83%AB%E3%83%91%E3%82%AB%E3%81%AE%E6%95%B0%E3%81%8C%E4%B8%96%E7%95%8C%E4%B8%80%E5%A4%9A%E3%81%84%E5%9B%BD)してみます。

すると、AI による概要として次の解答が得られました。


> アルパカの数が世界で最も多い国はペルーです。世界のアルパカの約80〜85％がペルーに生息しており、アンデス山脈の標高4,000メートル前後の高地で主に放牧されています。
> 
> その他の主な生息国としては、ボリビアやチリなどのアンデス地域が続きます。

よって問題の答えはペルーであり、フラグは Alpaca{Peru} となります。

毛は高級な繊維として、また意外にも身近な食材としても親しまれているみたいです。
