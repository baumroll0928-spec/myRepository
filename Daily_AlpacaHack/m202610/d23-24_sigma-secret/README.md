# Σecret

## 問題

わわわわ～！

```py
FLAG = getenv("FLAG", "Alpaca{REDACTED}").encode()
HALF_SIZE = 4
BLOCK_SIZE = 2 * HALF_SIZE
OFFSET = 1 << (8 * HALF_SIZE)

flag = FLAG + bytes(-len(FLAG) % BLOCK_SIZE)

for i in range(0, len(flag), BLOCK_SIZE):
    block = flag[i : i + BLOCK_SIZE]
    x = int.from_bytes(block[:HALF_SIZE], "big")
    y = OFFSET + int.from_bytes(block[HALF_SIZE:], "big")

    print([sum(v**k for v in (x, y)) for k in range(1, 3)])

)
```

## 概要

フラグをバイナリに変換したものをサイズがブロックサイズ(=8)の倍数になるように`b'\x00'`でパディングし、これを頭からブロックごとに処理します。

ブロックごとの処理は、前半部を整数化した`x`と後半部分を整数化し$`2^{32}`$を足した`y`について、 $`x + y`$ と $`x^{2} + y^{2}`$ を出力します。

どうすればこれらの情報からフラグを復元できるのでしょうか？

## 解法

まずは数学のお話です。

ブロックごとに与えられた情報を`a`,`b`とおきます。

$`a = x + y`$ ・・・①

$`b = x^{2} + y^{2}`$ ・・・②

すると、①より、

$`y = a - x`$

なので、これを②に代入して`b`を移項すると、

$`x^{2} + (a - x)^{2} - b = 0`$

となります。

この二次方程式を解くと2つの整数解が求まるはずですが、`x`と`y`は対称なので、片方が`x`、もう片方が`y`になります。

`x`は$`2^{32}`$未満、`y`は$`2^{32}`$以上になるので、必ず $`x < y`$ となることから、2つの解のうち小さい方が`x`、大きい方が`y`だとわかります。

`x`と`y`が求まればブロックを復元するのは容易ですが、どうやって求めましょうか？

二次方程式の解の公式

$`ax^{2} + bx + c = 0 (a \ne 0) ⇔ x = \frac{-b \pm \sqrt{b^{2} - 4ac}}{2a}`$

を使って自力で解いてもいいですが、Pythonのsympyモジュールには方程式を解いてくれるしくみがあるのでこれを利用します。

```py
def find_x_and_y(a:int, b:int)->list[int]:
    from sympy import Symbol, solve
    x = Symbol('x')                       # 変数の定義
    expr = x ** 2 + (a - x) ** 2 - b      # 方程式を組み立てる
    sol = solve(expr, x)                  # 解く
    assert all(v.is_Integer for v in sol) # 念のため全ての解が整数であるかチェックする
    return sorted(map(int, sol))          # int化し昇順ソートして返す
```

`a`と`b`から`x`と`y`を求める関数を作ってみました。

出力データは、いつもは`output.txt`からコピペするところですが、今回はサーバーから取得する形式になっているので、ncコマンドで接続して取得します。


取得できたので、これをループで扱いやすいように二次元配列にします。

```py
data = [
    [7059925944, 36753806406090996818],
    [7529621219, 37431319225856175793],
    [8117736419, 41819863599869990065],
    [8184645837, 42791751259032773765],
    [5929923965, 21119827383217127177],
]
```

あとはこれらを使ってブロックごとに復元していけばフラグを得ることができます。

```py
HALF_SIZE = 4
OFFSET = 1 << (8 * HALF_SIZE)

flag = b''
for a, b in data:
    x, y = find_x_and_y(a, b)
    flag += int.to_bytes(x, HALF_SIZE, "big")
    flag += int.to_bytes(y - OFFSET, HALF_SIZE, "big")
print(f"{flag = }")
```
